Build Robust RAG Systems:
Analyze & Benchmark AI Failures

A comprehensive dataset and evaluation pipeline for identifying and classifying Retrieval-Augmented Generation errors — retrieval gaps, hallucinations, contradictions, citation faults and reasoning slips — curated for the Kaggle community.

03 · EVALUATION

Retrieval & classification, measured honestly

Zero-shot FAISS baseline (all-MiniLM-L6-v2, index built in Colab) and a TF-IDF + Logistic Regression failure classifier on the held-out test split. Macro-F1 reported alongside accuracy because the label distribution is imbalanced.
